1. 產品目標與邊界
為小型水電工程團隊提供手機優先的工程、現場、材料、採購、報價、財務及維修管理。
支援多組織資料隔離；一般工程資料供有效成員依權限協作，敏感財務、薪資與門禁資料另行授權。
第一版不自動開立官方電子發票；不把出勤時數直接視為薪資，不把收款直接視為會計收入。
系統以繁體中文、台灣時區 Asia/Taipei、NT$ 為主要操作環境。

4. 核心跨模組不變條件
所有關聯業務資料必須位於同一 organization_id，採用後端授權與 PostgreSQL RLS 雙重保護。
工程／維修的正式報價只能對應有效且一致的業務主體；已接受報價與已接受追加減是合約金額來源。
領料≠耗用；採購核准≠收貨≠付款；請款≠收款≠預收款抵充≠會計收入。
已發布報價、正式庫存異動、金流及稽核紀錄不可直接覆寫。
金額與數量採精確 decimal；API 使用字串傳遞精確值；所有關鍵交易具備冪等性及並行控制。
照片及敏感檔案私有，禁止在前端暴露高權限金鑰。
5. API 與資料設計交接要求
API 前綴 /api/v1；統一成功 {data,meta} 與失敗 {error:{code,message,details,request_id}}。
錯誤碼至少涵蓋 401、403、404、409、422、429；需防止跨組織資源存在性洩漏。
正式寫入使用 Idempotency-Key；並行修改使用 version／If-Match 等一致機制。
資料庫使用 UUID、TIMESTAMPTZ（儲存 UTC）、NUMERIC 精確金額／數量，並建立組織範圍外鍵、唯一索引及 RLS。
正式 SQL Migration、OpenAPI 規格及各表完整欄位／約束，應在 DOC-02／DOC-03 另行完成，不以本 PRD 代替。
