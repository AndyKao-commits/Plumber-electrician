# 跨模組整合規則 INT-01～INT-12

來源：全系統整合審查 V2.2

| 編號 | 問題 | 統一設計 |
|---|---|---|
| INT-01 | 工程與維修報價來源不同 | 共用報價模型，分別關聯工程或維修 |
| INT-02 | 工程與維修材料可能重複扣帳 | 共用唯一庫存流水帳 |
| INT-03 | 領料與實際耗用混淆 | 區分庫存位置轉移與消耗 |
| INT-04 | 報價版本與合約金額混淆 | 以客戶已接受版本為基準 |
| INT-05 | 追加減尚未接受就計入合約 | 只計入已接受追加減 |
| INT-06 | 請款、收款與收入混淆 | 分別建模及計算 |
| INT-07 | 出勤跨日造成重複計算 | 以完整班次為主 |
| INT-08 | 工程參與人員與操作權限混淆 | 有效團隊成員具一般工程權限 |
| INT-09 | 施工照片與業務紀錄重複保存 | 共用媒體資產與關聯表 |
| INT-10 | 離線重送造成重複交易 | 操作識別碼＋冪等 |
| INT-11 | 各模組稽核格式不一致 | 共用稽核事件模型 |
| INT-12 | 報表直接使用未確認資料 | 只採用正式口徑資料 |

最需嚴格測試：INT-02、INT-03、INT-06、INT-10。

## 必過 E2E（對話列 8 組）

| 測試 | 情境 |
|---|---|
| E2E-01 | 建立工程至施工結案 |
| E2E-02 | 採購至材料實際耗用 |
| E2E-03 | 緊急採購連續申請額度 |
| E2E-04 | 報價至追加減及收款 |
| E2E-05 | 維修至保固與結案 |
| E2E-06 | 跨日出勤與工地切換 |
| E2E-07 | 離線施工回報與照片重送 |
| E2E-08 | 權限撤銷及跨組織存取 |
