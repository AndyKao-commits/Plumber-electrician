# LINE 圖文訊息 V1

本文件描述聊天訊息中的 **Imagemap Message（圖文訊息）**。它與聊天室底部的 Rich Menu（圖文選單）是兩套獨立功能。

## 觸發方式

- 新增好友（`follow`）：依 LINE 綁定狀態回覆對應面板。
- 傳送「功能選單／功能面板／工作面板／師傅工作面板／管理面板／開啟選單／選單」：依目前綁定身分回覆對應面板。
- 成功輸入 LINE 綁定碼：綁定成功文字後接續回覆對應面板。

維持 Reply-only，不主動推播。

## 面板判斷

| 條件 | 面板 |
| --- | --- |
| 查無 `profiles.line_user_id` | 帳號綁定（3 區） |
| `role` 為 `boss` / `owner`，或 `access_template = owner` | 管理面板（6 區） |
| 其他已綁定帳號 | 師傅工作面板（6 區） |

管理面板只對「老闆／等同老闆權限」顯示。點擊後，網站與資料庫仍須依登入者重新驗證權限；群組中看到面板不代表取得權限。

## 圖片

每個面板提供 LINE 要求的五種 PNG 寬度：`240`、`300`、`460`、`700`、`1040`。圖片皆為正方形，單檔小於 10 MB。

公開路徑：

```text
/line/imagemap/{staff|manager|binding}/{240|300|460|700|1040}
```

Vercel 以無副檔名網址改寫到對應 `.png` 靜態檔。

## 點擊區

師傅／管理面板使用 3 欄 × 2 列：

| 序號 | x | y | width | height |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0 | 0 | 346 | 520 |
| 2 | 346 | 0 | 346 | 520 |
| 3 | 692 | 0 | 348 | 520 |
| 4 | 0 | 520 | 346 | 520 |
| 5 | 346 | 520 | 346 | 520 |
| 6 | 692 | 520 | 348 | 520 |

帳號綁定面板使用 3 列：`520 + 260 + 260 = 1040`。

## 功能對應

### 師傅工作面板

| 功能 | 動作 |
| --- | --- |
| 上傳照片 | 傳送文字，進入現有照片流程 |
| 出勤打卡 | 傳送文字，進入現有出勤／LIFF 流程 |
| 紀錄地點 | 傳送文字，進入現有地點流程 |
| 新增記帳 | 傳送文字，進入現有支出／收款流程 |
| 待辦事項 | 傳送文字，顯示個人待辦 |
| 個人中心 | 開啟網站 `/profile` |

### 管理面板

依序開啟 `/notifications`、`/team`、`/sites`、`/expenses`、`/quotes`、`/salary`。

### 帳號綁定

依序為開啟 `/profile`、傳送「帳號綁定教學」、開啟網站首頁。
