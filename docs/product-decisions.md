# 工程管家｜已確認產品決策
來源：[ChatGPT 規劃對話](https://chatgpt.com/share/6af27b2e-31d8-83ee-9de3-c8287529caeb)
暫定名稱：工程管家（水電工程行管理系統）

## 已確認

- **角色**：僅老闆與員工；無會計帳號。會計由老闆匯出報表。
- **權限架構**：全員共用工作功能；老闆專屬管理權限。
- **工地資料**：每個工地獨立頁面；全員可查看所有工地紀錄。
- **工程類型**：正式工程 + 臨時維修；臨時維修可轉正式工程。
- **技術架構**：GitHub + Cloudflare Workers + Supabase + Cloudflare R2；手機優先 PWA。
- **離線**：第一版必要功能：沒網路也可操作，連線後自動同步。
- **LINE 整合**：官方帳號；私訊 + 公司群組皆支援；快速按鈕為主、文字指令為輔。
- **LINE 群組歸檔**：施工照片與文字採「辨識後確認」再歸檔。
- **打卡流程**：先一鍵上班打卡，地點與工地稍後補登；切換工地不必重新上下班。
- **GPS**：輔助定位，不影響一鍵打卡。
- **午休**：不自動扣除休息時間。
- **薪資制度**：每位員工可分別設定月薪、日薪或時薪；僅老闆可改薪資設定。
- **薪資可見**：員工可查看自己的薪資明細，不可看他人。
- **薪資週期**：每月結算一次。
- **代墊款**：可隨時核銷，也可月底集中付款。
- **材料庫存**：簡易材料庫存。
- **材料領用**：重要材料即時記錄，一般耗材可批次登記。
- **庫存盤點**：所有員工都能直接調整庫存，無需老闆審核。
- **工程結案**：員工可提出結案，老闆正式確認。
- **保固提醒**：保固到期前提醒老闆。
- **維修派工**：所有員工都能建立維修案件；僅老闆可正式派工。
- **排程異動**：員工可提出調整，老闆確認後生效。
- **請假**：員工申請，老闆確認。
- **補打卡**：員工可申請補打卡，老闆確認後生效。
- **出勤異常提醒**：每天固定時間彙整，再透過 LINE 提醒。
- **每月出勤確認**：員工可確認，但不阻擋薪資結算。
- **薪資更正**：員工可提出更正申請，老闆核准後建立正式更正單。
- **薪資補發**：老闆可選立即補發或併入下次薪資，依法定期限控管。
- **資金帳戶**：區分銀行帳戶與現金帳戶。
- **員工零用金**：員工可登記自己保管的零用金收支。
- **零用金補充**：員工可申請補充，老闆確認後撥款。
- **一般採購核准**：單筆達 NT$3,000（含）以上需老闆事前核准。
- **緊急採購**：符合預先授權條件可先買事後核對；預設單次上限 NT$5,000。
