# LINE 圖文選單（V1）

上排：上傳照片｜出勤打卡｜紀錄地點  
下排：記帳｜待辦事項｜進入工地

| 按鈕 | LINE 動作建議 | Webhook 行為 |
|---|---|---|
| 上傳照片 | 傳文字 `上傳照片` | 現流（工地→類型→連傳圖） |
| 出勤打卡 | 傳文字 `出勤打卡` | 上班／下班（可不選工地） |
| 紀錄地點 | 傳文字 `紀錄地點` | 分享位置或選工地＝足跡 |
| 記帳 | 傳文字 `記帳` | 選支出／收款現流 |
| 待辦事項 | 傳文字 `待辦事項` | 查詢／完成 |
| 進入工地 | URI `https://plumber-electrician-seven.vercel.app/` | 開網站主頁（文字「進入工地」也可） |

請在 LINE Developers → Messaging API → 圖文選單依上表重建並套用。
