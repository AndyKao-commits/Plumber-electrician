# 工程管理系統｜品牌視覺規範

本規範是網站、LINE 圖文選單、圖文訊息與 Flex Message 的共同設計基準。

## 角色配色

| 使用情境 | 背景 | 卡片／表面 | 強調色 | 文字 |
| --- | --- | --- | --- | --- |
| 一般員工 | `#172C3C` | `#254657` | `#9CD9D2` | `#FFFFFF` |
| 管理者 | `#222C38` | `#354353` | `#E5C58C` | `#FFFFFF` |

- 一般員工以薄荷青表示主要操作、目前選取及功能焦點。
- 老闆及被授予老闆等級權限者，以香檳金表示主要操作、目前選取及管理權限。
- 角色差異只更換強調色與深色表面，不改變元件結構及操作位置。

## 功能狀態色

| 狀態 | 色碼 | 用途 |
| --- | --- | --- |
| 完成／收款 | `#276C60` | 完成、成功、已收款、上班中 |
| 支出／異常 | `#995043` | 支出、錯誤、異常、需注意 |
| 等待／審核 | `#B89552` | 待審核、處理中、未完成 |
| 停用／取消 | `#64748B` | 停用、取消、不可操作 |

狀態色只代表業務狀態，不因使用者角色改變。

## 元件規則

- 深色背景、低飽和度，不使用高亮橘色或大面積漸層。
- 卡片使用 14–16px 圓角，邊框低對比，陰影保持克制。
- 主要按鈕使用角色強調色；次要按鈕使用透明底與細邊框。
- 圖示採簡潔線條式，網站與 LINE 同一功能維持同一圖示與顏色。
- 繁體中文為主；英文只作短標籤或輔助說明。
- 白字用於深色表面；薄荷青與香檳金上的文字必須使用對應深色底色，維持可讀性。
- 管理者畫面不另建一套版型，以香檳金點綴識別權限即可。

## 實作對照

- 網站透過 `data-ui-tone="staff|admin"` 切換角色色票。
- LINE Flex Message 使用 `LINE_BRAND.staff`／`LINE_BRAND.admin`；綁定帳號為老闆或 `access_template = owner` 時套用管理者色票。
- 所有新增介面應優先使用共用色彩變數，不直接寫入新的臨時色碼。
